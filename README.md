## 1. О проекте

Проект посвящён поддержке менеджера по закупкам: анализу истории продаж и складских данных для формирования объяснимых рекомендаций по пополнению запасов. Цель — помочь учитывать регулярный спрос, возможную сезонность, периоды отсутствия товара, разовые крупные продажи, остатки и ожидаемые поставки при подготовке заказа.

**Для кого:** закупщики, менеджеры по товарным запасам и сотрудники, отвечающие за планирование поставок.

**Важно:** описание выше — назначение решения по постановке задачи, а не подтверждение того, что все перечисленные возможности уже реализованы.

## 3. Пользовательский сценарий

**Предполагаемый сценарий по описанию кейса; требуется подтвердить по работающему приложению:**

1. Менеджер загружает доступные данные о продажах, остатках и поставках или открывает демонстрационный набор данных.

5. При необходимости корректирует количество и подтверждает результат.
6. Экспортирует подготовленный заказ, если экспорт реализован.
