# UI/UX Specification & Design System
## Система поддержки закупок на основе прогноза спроса

## 1. Рекомендуемый готовый шаблон (UI Template)
* **Базовый фреймворк:** React / Next.js + Tailwind CSS
* **Компоненты таблицы и дашборда:** [Shadcn UI Dashboard Template](https://github.com/shadcn-ui/ui)
* **Библиотека графиков спроса:** [Recharts](https://recharts.org/) / [Tremor UI](https://www.tremor.so/)

---

## 2. Экранная структура (Layout)

### 📊 Главный дашборд (Workbench / Orders)
1. **Сводные карточки (KPIs):**
   - Всего товаров к закупке
   - Общая сумма заказа
   - Позиции с риском дефицита (Stockout Risk)
2. **Фильтры:**
   - Поставщик (Select)
   - Категория товара
   - Уровень риска (Критический / Норма / Завышен)
3. **Таблица рекомендаций (Data Grid):**
   - `SKU` | `Наименование` | `Поставщик` | `Остаток` | `В пути` | `Прогноз` | `Рекомендация` | `Ручная правка` | `Причина/Флаг`

---

## 3. Цветовая схема (Design Tokens)

- **Primary:** `#2563EB` (Blue 600) — Кнопки действий, экспорт.
- **Background:** `#F8FAFC` (Slate 50) — Общий фон.
- **Card Surface:** `#FFFFFF` — Таблицы и карточки.
- **Stockout / Critical Warning:** `#DC2626` (Red 600) — Закончился запас, срочная закупка.
- **Seasonality / Caution:** `#D97706` (Amber 600) — Корректировка на сезонность / аномальный заказ.
- **Normal / OK:** `#059669` (Emerald 600) — Запасы в норме.

---

## 4. Графики детального анализа (Item Modal)
При клике на товар открывается модальное окно с:
- **Line Chart (Recharts):** История продаж за 12 месяцев + пунктирный прогноз на 30–90 дней.
- **Area Highlight:** Выделение периодов Stockout (когда товара не было на складе).
- **Explainability Tooltip:** Расчёт формулы (Базовый спрос × Сезонность - Остаток - В пути).
