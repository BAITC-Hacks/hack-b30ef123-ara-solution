# 🎨 ТЗ НА РАЗРАБОТКУ UI/UX ИНТЕРФЕЙСА: HACKALEM REPLENISHMENT MVP

## 1. КОНЦЕПЦИЯ И ЦЕЛЬ ИНТЕРФЕЙСА

Проект: Single Page Application (SPA) на React + Tailwind CSS для системы поддержки принятия решений по закупкам (Explainable AI / Понятный ИИ).

Главная UX-цель: Создать настолько интуитивный, визуальный и наглядный интерфейс, чтобы в алгоритме расчёта закупки без инструкции разобрался даже ребёнок, но при этом сохранить стиль аккуратного и надёжного Enterprise-инструмента.

--------------------------------------------------------------------------------

## 2. ЦВЕТОВАЯ ПАЛИТРА И ТИПОГРАФИКА

Цветовая палитра:
- Фон страницы: #F8FAFC (Slate-50) — мягкий светлый фон.
- Карточки и таблицы: #FFFFFF (Pure White) — белоснежные плашки с тенью shadow-sm и скруглением rounded-2xl.
- Основной акцент (Primary): #2563EB (Blue-600) — глубокий синий для ключевых кнопок, активных вкладок и акцентов.
- Семантические статусы:
  * 🔴 Дефицит / Срочно (Critical): #EF4444 (Red-500)
  * 🟡 Сезонность / Внимание (Warning): #F59E0B (Amber-500)
  * 🟢 Норма / В пути (Success): #10B981 (Emerald-500)
  * ⚪ Нейтральный текст (Muted): #64748B (Slate-50)

Типографика:
- Основной шрифт: Inter или Roboto (без засечек).
- Цифры в таблице: Включить моноширинный режим (font-mono / tabular-nums) для идеального вертикального выравнивания чисел.

## 4. ДЕТАЛИЗАЦИЯ СЕКЦИЙ

1. Шапка сайта (Header):
- Слева: Логотип HackAlem Procurement с яркой иконкой молнии/закупки и бейджем MVP Demo.
- По центру: Переключатель бренда — крупные вкладки [ IEK ] и [ Systeme Electric ].
- Справа: Индикатор соединения с сервером c анимацией пульсации (● API Ready на зеленом фоне).

2. Панель параметров расчёта (Control Bar / Step 1):
Светлая карточка с пошаговым заголовком «Шаг 1. Параметры расчета»:
- Выпадающий список «Поставщик» (с фильтрацией по выбранному бренду).
- Поле ввода «Дней планирования» (по умолчанию 30).
- Поле ввода «Demo Lead Time (дней)» (по умолчанию 7).
- Яркая синяя кнопка действия «Рассчитать закупку» с иконкой молнии или калькулятора.

3. Сводные метрики (KPI Cards / Step 2):
Три крупных визуальных блока перед таблицей:
- 📦 Всего позиций: Крупное число (например, 24 SKU).
- ⚠️ Срочная закупка: Число на красном фоне (например, 3 позиции) — с акцентом дефицита.
- 🚚 Итоговый объём заказа: Суммарное количество штук после учета правок (например, 1 450 шт.).

4. Рабочая таблица (Main Workbench / Step 3):
Таблица с прозрачным фоном, разделительными линиями и плавным подсвечиванием строк при наведении:
- Колонки:
  1. Статус: Цветовой бейдж (Красный = Дефицит, Жёлтый = Сезонность/Выброс, Зеленый = Норма).
  2. SKU и Наименование: Код товара моноширинным шрифтом и читаемое название.
  3. Текущий остаток: Число с иконкой склада.
  4. В пути: Число с иконкой грузовика.
  5. Прогноз спроса: Рассчитанный спрос с иконкой тренда.
  6. Рекомендуем заказать: Крупный жирный шрифт в цветах бренда.
  7. Ваша правка: Белое аккуратное поле ввода (Input number), где менеджер может переопределить количество.
  8. Почему столько?: Кнопка ℹ️ Объяснить с легким синим фоном для открытия модального окна.

5. Финальная панель действий (Sticky Footer / Step 4):
Плавающая нижняя панель, закрепленная внизу экрана:
- Слева: Чекбокс ☑ Я проверил рекомендации и подтверждаю итоговые цифры.
- Справа: Зеленая кнопка «Скачать заказ в CSV» (активна только после установки чекбокса).

## 5. ВСПЛЫВАЮЩЕЕ ОКНО «ОБЪЯСНЕНИЕ ФОРМУЛЫ» (EXPLAINABILITY MODAL)

При клике на кнопку ℹ️ Объяснить открывается всплывающее окно, выполненное в формате пошагового кассового чека или понятной арифметики 3-го класса.

Структурные шаги внутри окна:

1. Шаг 1: Потребность (Фон светло-синий)
- Заголовок: Прогноз спроса (на 30 дн.): 110 шт.
- Детализация: Базовый спрос (90 шт.) + Сезонный прирост (+10 шт.) + Простой (+10 шт.).
- Плашка аномалий: ⚠️ Отфильтрован закуп-выброс (300 шт. от 12.05).

2. Шаг 2: Упущенная выгода / Stockout (Фон светло-желтый)
- Заголовок: + Компенсация отсутствия товара: +10 шт.
- Подсказка: Товара не было на складе 4 дн. Добавлены упущенные продажи.

3. Шаг 3: Наши ресурсы (Фон светло-зеленый)
- Заголовок: - Текущие ресурсы: -32 шт.
- Подсказка: Остаток на складе (12 шт.) + Уже едет в пути (20 шт.).

4. Шаг 4: Итоговая математика (Разделительная пунктирная черта)
- Строка расчета: (110 + 10) - 12 - 20 = 88 шт.
- Округление: Округление до кратности упаковок (по 10 шт.) = 80 шт.

5. Финальная плашка:
- Крупный блок: Рекомендуем заказать: 80 шт.

## 6. UX-СОСТОЯНИЯ (LOADING, ERROR, EMPTY)

- Состояние загрузки (Loading): Во время клика на «Рассчитать» таблица закрывается плавной пульсирующей заглушкой (Skeleton Loader).
- Пустое состояние (Empty State): Если данные не выбраны, по центру выводится подсказка: «Выберите поставщика и нажмите "Рассчитать закупку"».
- Ошибки (Error State): При сбое сервера появляется плашка с предупреждением и кнопкой Повторить.
