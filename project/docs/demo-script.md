# Demo script

## Scenario

1. Launch the application stack with Docker Compose.
2. Open the frontend in the browser.
3. Show the main user flow from landing state to result generation.
4. Explain how the API contract and backend processes support the UI.
5. Highlight data samples and generated outputs from the demo dataset.

## Talking points

- Show the system setup and architecture clearly.
- Emphasize real workflow value rather than only UI polish.
- Keep the narrative focused on business outcome and speed of delivery.
